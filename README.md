# Global Country Data Analysis

## What it does
Fetches live country data from REST countries API, stores it in a SQL database, and analyzes population, region, and area statistics using SQL queries.

## Tech Used
- Python (requests, pandas)
- SQLite (SQL database)
- Matplotlib (visualization)

## Key Findings
- Asia has the highest total population among all regions, with approximately 4604576074 people.
- The top 3 most populous countries are China, India and Unit States of America.
- Africa has the most countries (60), while Polar, Antarctic Ocean and Antarctic has only 1.

## How to run
Open the .ipynb file in Google Colab and run all the cells.
